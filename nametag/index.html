Macam mana nak order?+
Pilih jenis, saiz & kuantiti, tekan Order via WhatsApp — quote auto masuk dalam chat. Kami sahkan, kau hantar senarai nama + logo, dan kami mula cetak.

    
Berapa lama nak siap?+
Order biasa lebih kurang 1–3 hari bekerja ikut kuantiti. Urgent (+RM10/order) boleh untuk Basic, Government & UV Print ikut slot. Epoxy perlu masa lebih, jadi tak boleh urgent.

    
Boleh letak logo atau jata?+
Boleh. Hantar file PNG / JPG / PDF. Tulis dalam ruang Catatan jenis logo yang nak.

    
Saiz name tag berapa?+
Basic: 70mm x 20mm atau 75mm x 25mm. Government/Engrave & Epoxy: 25x75mm. UV Print custom ikut design.
